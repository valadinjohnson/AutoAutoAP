🥚 Local setup guide

Get AutoAutoAP running on your machine

AutoAutoAP plans ascension chains for Egg, Inc.'s Virtue Prestige system — the sequence of Truth Egg checkpoints that gets you to a target the fastest. Follow the steps below top to bottom; use the switch above to see the exact commands for your platform.

What you'll have
The planner running at localhost:4173, open in your browser
Time needed
10–20 minutes, most of it package downloads

Before you start

One-time installs
Node.js 24+
Runs the build tooling. 26 works too.
pnpm
The package manager this project's workspace is built with — not npm or yarn.
protoc
Compiles Egg, Inc.'s .proto API definitions into TypeScript the app imports from.
make
Runs the build recipes in each folder's Makefile.
Python 3.9+
Only needed for the optional batch chain-search script later.

Build & run

Steps 1–6
1

Install the toolchain

One Homebrew line covers everything: Node, pnpm, protoc, Python, and Git.

Chocolatey covers everything in one line. This also installs Git for Windows, which brings Git Bash — use that terminal for every command below, since make and && chaining need it.

zsh — Terminal.app
# if you don't have Homebrew yet:
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# then:
brew install node pnpm protobuf python git
PowerShell (Run as Administrator)
# if you don't have Chocolatey yet:
Set-ExecutionPolicy Bypass -Scope Process -Force
[System.Net.ServicePointManager]::SecurityProtocol = [System.Net.ServicePointManager]::SecurityProtocol -bor 3072
iex ((New-Object System.Net.WebClient).DownloadString('https://community.chocolatey.org/install.ps1'))

# then, in a new admin PowerShell window:
choco install git nodejs-lts pnpm protoc make python -y

After this finishes, close PowerShell and open Git Bash (search for it in the Start menu) — use it for every step from here on.

2

Open a terminal in the project folder

Wherever you saved AutoAutoAP-ascension-chain-search — a download, a USB drive, a clone from wherever you got it — navigate there first.

zshGit Bash
cd path/to/AutoAutoAP-ascension-chain-search
3

Install workspace dependencies

This is a pnpm workspace — 23 sub-projects share one install. Always run this at the repo root, never inside a subfolder.

repo root
pnpm install
4

Generate the protobuf bindings

Every other package imports the Egg, Inc. API types from lib/proto — but that folder is generated, not committed. This is the step people skip, and it's the one that produces a wall of Cannot find module '../proto' errors if you do.

repo root → lib/
cd lib
make
5

Build the planner

Compiles the Vue app into a static bundle in dist/.

lib/ → wasmegg/ascension-planner
cd ../wasmegg/ascension-planner
pnpm fastbuild
6

Run it

Serves the build locally. Leave this terminal window open while you use the app.

wasmegg/ascension-planner
pnpm serve
Open http://localhost:4173/ascension-planner/ in your browser
Heads up: the app needs a secure context to work — localhost is fine, but serving it over plain HTTP on your LAN (e.g. another device hitting your IP address) will break silently, because the browser's crypto APIs refuse to run.

Going further

Optional

The page you just opened is the interactive planner — pick targets, hit Generate Plan, get one chain. There's a separate command-line tool for a heavier job: searching thousands of candidate chains to find the genuinely fastest one.

Verify the build is faithful

Confirms your machine's simulator matches the reference result to the hour, before you trust a multi-hour search.

ascension-planner
pnpm search:build
node dist-search/fastsearch.js \
  --backup your_backup.json --final 490 \
  --start-date 2026-09-04 --start-time 18:51 \
  --timezone America/Denver --force-continue
Search for the best chain

--player-id fetches your save over the network; --backup file.json runs fully offline instead.

ascension-planner
python scripts/autoplan.py \
  --player-id EIxxxxxxxxxxxxxxxx \
  --backup me.json \
  --effort balanced --jobs 12 --yes
⚠ Treat your player ID as a secret. The Egg, Inc. API will hand your entire save to anyone who has it — that's exactly what --player-id requests. Don't paste a real one into a screenshot, log, or chat.

Troubleshooting

What each error actually means
Cannot find module '../proto' or UNRESOLVED_IMPORT›
You skipped Step 4. Go to the repo root, cd lib, and run make — this generates the file every other package is importing from.
No targets specified and no makefile found›
You ran make from the wrong folder — there's no top-level Makefile at the repo root. cd lib (or the specific project folder) first, then run make there.
protoc: command not found / pbjs fails›
protobuf isn't installed, or your terminal was opened before the install finished. Re-run the Step 1 install command, then open a new terminal window so it picks up the updated PATH.
ENOENT: no such file or directory, open 'blind_main.json'›
Expected — that filename is a placeholder example from someone else's private backup, not something shipped in this repo. Point --backup at your own save file instead, or fetch one live with --player-id.
'make' is not recognized / && was unexpected›
You're running commands in PowerShell or Command Prompt. Use Git Bash instead — it's installed alongside Git for Windows and behaves like the macOS/Linux examples throughout this guide.
